# Portfolio de Mateo Nicolás González

React + Vite + Tailwind CSS v4.

## Usar
```bash
npm install
npm run dev      # desarrollo
npm run build    # producción (carpeta dist)
```

## Personalizar
Todo el contenido (textos, proyectos, tecnologías, links, email) está en `src/data.js`.
Los colores están en `src/index.css`, dentro de `@theme`.

## Publicar
Subilo a un repo de GitHub e importalo en Vercel: detecta Vite solo.
